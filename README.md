# Introduction to Working with Data

This repository contains the source for a PreTeXt book on An Introduction to Working with Data.

## Status

Chapters 1-4 are now complete. Chapters 5-10 are in progress, and will be updated weekly.

## Chapter structure

Each chapter generally follows the same structure:

1. **A real case study** - currently (ideally) Kenya-based as that is the target audience here. This introduces the concept through a story that requires no prior statistical knowledge.
2. **A STACK question** - prompting the reader to think deeply about the problem. Most of these are already written and mainly need to be slotted into the relevant chapters.
3. **An illustrative example using software** - introducing the methods and statistics in a data-first way, following the ideas in Cobb's 2015 paper.
4. **Exercises** - with the option to add further STACK questions here too.
